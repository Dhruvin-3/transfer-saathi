# Transfer Saathi Next.js demo

## Run locally

```powershell
npm install
npm run dev
```

Open http://localhost:3000. The app writes generated output to `.next-16`, so it will not reuse a stale Next 15 cache.

## Safety

This app uses fictional, local-only demo records. It does not connect to any government service, collect identity data, accept Aadhaar numbers or OTPs, or use government branding. All verification, document review and appointments are simulated.
